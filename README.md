"Warning Label for Humans: One Line, Big Laugh" — a single-line safety
warning label that should come printed on every human being, 160 characters
or fewer.

## Entry

> WARNING: This human will type for three minutes, delete every word, and reply 'lol'.

84 characters. The laugh lands on the last word: three minutes of careful
typing, deleted, replaced by "lol" — recognition of how humans actually
text, in the wording of a real printed label.

## Run

`main.py` (Python 3.13, standard library only) writes the entry to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`):

```sh
python3 main.py
```
